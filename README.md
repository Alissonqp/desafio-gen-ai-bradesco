## 📝 Visão Geral
O **GuanabaraAI** é um assistente de inteligência artificial configurado para atuar como um **Segundo Cérebro** especializado na didática de Gustavo Guanabara (Curso em Vídeo/Estudonauta). 

Diferente de IAs genéricas, este projeto foca em **ensinar a lógica** antes do código, utilizando as analogias, o tom de voz motivacional e a progressão pedagógica que transformaram a educação tecnológica no Brasil.

---

## 🎯 O Desafio (A Dor)
Muitos estudantes de programação sofrem com o "vazio" entre assistir a uma aula e conseguir resolver um problema sozinho.
- **O Problema:** IAs comuns entregam a resposta pronta, matando o raciocínio lógico.
- **A Solução:** Criar um mentor digital que utilize a **Engenharia de Contexto** para guiar o aluno passo a passo, exatamente como o Guanabara faria em sala de aula, focando em "Algoritmos" como base de tudo.

---

## 🚀 Minha Abordagem
Para construir este repositório de conhecimento, segui os pilares da metodologia apresentada nos cursos:

### 1. Curadoria de Dados (Knowledge Base)
Utilizei transcrições e materiais de apoio dos cursos de:
* **Algoritmos:** Onde tudo começa.
* **Python (Mundos 1, 2 e 3):** Estruturas, listas e dicionários.
* **Java & HTML5:** Conceitos históricos e sintaxe básica.

### 2. Engenharia de Prompt (Persona)
A IA foi instruída a:
* Nunca entregar o código de primeira sem explicar a lógica.
* Utilizar analogias do cotidiano (como a "xícara de café" ou o "armário de variáveis").
* Manter o entusiasmo e usar bordões icônicos para criar conexão emocional.

## ✅ Resultados e Lições Aprendidas
* **Aprendizado Ativo:** O projeto provou que uma IA "teimosa" (que se recusa a dar a resposta e prefere ensinar) é muito mais eficaz para o aprendizado de longo prazo.
* **Conexão Humana:** A importância da *Persona*. Quando o aluno sente que está conversando com um mentor conhecido, o medo de errar diminui.
* **Domínio de Contexto:** Aprendi a estruturar grandes volumes de dados de texto para alimentar modelos de linguagem de forma eficiente.
