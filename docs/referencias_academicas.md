# 📖 Referências Técnicas e Pesquisas

Este projeto integra conceitos extraídos de materiais acadêmicos e reviews da comunidade:

1. **Gamificação no Ensino:** Baseado no artigo *"Uma Revisão Sistemática do Uso da Gamificação no Ensino de Programação"*, aplicamos mecânicas de feedback e progressão por níveis para evitar a evasão do aluno.
2. **Educação via Vídeo:** Referência ao TCC de Marcio Lopes Gevegy (UFF) sobre vídeos como alternativas didáticas eficazes em disciplinas com alto índice de reprovação.
3. **Impacto no YouTube:** Dados do estudo *"Explorando o YouTube como Fonte de Aprendizado para Desenvolvedores"*, que destaca o Python como porta de entrada para iniciantes.
4. **Validação da Comunidade:** Insights de fóruns (Reddit) e reviews (João Alves) que confirmam que a didática "passo a passo" do Guanabara é a mais recomendada para quem está no "nível zero".
